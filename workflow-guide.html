1

Code Your Project

30-60 minutes

Write your Python project, tutorial code, or creative coding experiment. This is where your content begins.

Best Practices: Keep your code clean, well-commented, and beginner-friendly. Think about what someone learning from your tutorial would need to understand.

Example: Let's say you're creating a Python Turtle Snake Game.

import turtle
import time
import random

# Screen setup
screen = turtle.Screen()
screen.title("Snake Game Tutorial")
screen.bgcolor("black")
screen.setup(width=600, height=600)

# Snake head
head = turtle.Turtle()
head.shape("square")
head.color("lime")
head.penup()
head.goto(0, 0)

# Game loop
while True:
    screen.update()
    time.sleep(0.1)
    head.forward(20)

What to prepare:

  • One or more .py files
  • Clear variable names and comments
  • Working, tested code
  • Optional: README explaining the code
2

Test Your Code

10-15 minutes

Before recording your tutorial or publishing, make sure the code runs perfectly from start to finish.

Test on a fresh Python environment if possible. Sometimes code works on your machine but fails for others due to missing imports or environment differences.

Testing checklist:

  • Code runs without errors
  • All imports are standard library or clearly documented
  • No hardcoded paths (like C:\Users\YourName\...)
  • Output matches your expectations
  • Code is beginner-friendly (if that's your audience)

Generate AI Input JSON

5 minutes

Use an AI assistant (ChatGPT, Claude, etc.) to generate a structured input JSON based on your project. This saves you from typing everything manually.

Copy this prompt and paste to your AI:

Generate an admin input JSON for my YouTube coding tutorial website.

I made a Python turtle project called "Snake Game Tutorial".

Return ONLY this JSON structure (no extra text):

{
  "title": "Snake Game - Python Turtle Tutorial",
  "description": "one sentence summary",
  "longDescription": "2-3 sentence detailed explanation",
  "category": "tutorial",
  "duration": "MM:SS",
  "youtubeUrl": "https://youtube.com/watch?v=...",
  "sourceRepo": "https://github.com/username/repo",
  "tags": ["python", "turtle", "game", "beginner"],
  "files": [
    {
      "filename": "snake.py",
      "language": "python"
    }
  ]
}

What to tell the AI:

  • Your project title
  • What the code does (1-2 sentences)
  • How many Python files you have
  • The difficulty level (beginner/intermediate)
The AI will output a clean JSON. Copy the entire JSON block — you'll paste it into the admin panel in the next step.

5

Choose Your Method

5-10 minutes

You have two ways to create the final JSON file. Both produce the same result — choose based on your preference.

Option A: Quick Add (Recommended)

Perfect when you have the AI-generated JSON from Step 3. The form auto-fills, then you can edit before downloading.

  1. Click Quick Add in the sidebar
  2. Make sure Video JSON tab is selected
  3. Paste your AI-generated JSON into the text area
  4. Click Parse & Fill Form
  5. Review the auto-filled form (all fields are editable)
  6. Edit the auto-suggested Video ID if needed (e.g., video-003)
  7. Add YouTube URL, duration, thumbnail filename if you have them
  8. Click Generate & Download JSON

Quick Add paste area screenshot

Option B: Manual Form

Full control over every field. Good when you don't have AI-generated JSON or prefer typing everything yourself.

  1. Click Manual Form in the sidebar
  2. Select Video JSON tab
  3. Click Suggest Next ID to auto-fill the ID field
  4. Fill in all fields manually
  5. Add tags (press Enter or comma after each tag)
  6. Add file entries (click Add File for multiple files)
  7. Toggle Has Live Link if you have a live demo
  8. Click Generate & Download JSON
After clicking Generate, a file named video-003.json (or your ID) will download to your computer. You'll also see a preview and a placement guide showing where to put files.
6

Place Files in Folders

5 minutes

Now that you have the generated JSON file, place it and your code files in the correct folders following this structure.

The admin panel shows you a placement hint after generating JSON. Follow that guide exactly.

Example for video-003:

assets/ ├── data/ │ └── videos/ │ └── video-003.json ← Generated JSON goes here │ ├── code/ │ └── video/ │ └── video-003/ ← Create this folder │ ├── snake.py ← Your Python file(s) │ └── food.py │ └── images/ └── videos/ └── video-003/ ← Optional: create if you have thumbnail └── thumbnail.jpg

Step-by-step file placement:

  1. JSON file:
    Move video-003.json to assets/data/videos/
  2. Create code folder:
    Create folder assets/code/video/video-003/
  3. Add Python files:
    Move snake.py and food.py into assets/code/video/video-003/
  4. Optional thumbnail:
    If you have a custom thumbnail, create assets/images/videos/video-003/
    and place thumbnail.jpg there.
    (If you skip this, an auto-generated thumbnail will be used)
File names must match exactly what you entered in the admin form. If the JSON says snake.py, don't name it Snake.py or snake_game.py.
7

Update Index Registry

2 minutes

The website needs to know your new video exists. Add it to the master index file so it appears on the site.

Open this file:

assets/data/index.json

Add your video entry to the videos array:

{
  "projects": [
    ...existing projects...
  ],
  "videos": [
    {
      "id": "video-001",
      "file": "assets/data/videos/video-001.json",
      "featured": true
    },
    {
      "id": "video-002",
      "file": "assets/data/videos/video-002.json",
      "featured": false
    },
    {
      "id": "video-003",
      "file": "assets/data/videos/video-003.json",
      "featured": true
    }
  ]
}

Field explanations:

  • id — Must match the ID in your video JSON
  • file — Path to your JSON file
  • featured — Set to true if you want this video to show on the homepage (max 3 featured videos display)
That's it! Your video is now registered and will appear on the Videos page and (if featured) on the homepage.
8

Test Locally

5-10 minutes

Before deploying to GitHub Pages, test everything locally to catch any mistakes.

Start a local server:

# Option 1: Python
python -m http.server 8000

# Option 2: Node.js
npx serve

# Option 3: VS Code Live Server extension
# Right-click index.html → "Open with Live Server"

Testing checklist:

  • Homepage loads without errors
  • Videos page shows your new video card
  • Clicking the video card opens the detail page
  • Video detail page displays title, description, tags correctly
  • Source code files are shown with syntax highlighting
  • Copy button works for each file
  • Copy All button combines all files correctly
  • Download buttons work (if multiple files, ZIP downloads)
  • Thumbnail shows (custom or auto-generated)
  • No 404 errors in browser console
Common mistakes to check:
• File paths in JSON match actual file locations
• File names are spelled exactly right (case-sensitive)
• index.json has correct ID and path
• No missing commas in JSON files

How to check browser console:

  1. Open your site in browser
  2. Press F12 or right-click → Inspect
  3. Click the Console tab
  4. Look for red errors — fix any that appear
9

Deploy to GitHub Pages

5 minutes

Once everything works locally, push your changes to GitHub to publish the new video live.

Git commands:

# 1. Check what files changed
git status

# 2. Add all new/modified files
git add .

# 3. Commit with a clear message
git commit -m "Add video-003: Snake Game Tutorial"

# 4. Push to GitHub
git push origin main
GitHub Pages automatically rebuilds your site within 1-2 minutes after you push. Refresh your live site to see the new video.

Verify deployment:

  1. Go to your GitHub repository → Actions tab
  2. You should see a workflow running (yellow dot) or completed (green checkmark)
  3. Wait 1-2 minutes, then visit your live site: https://yourusername.github.io/yoursite/
  4. Navigate to Videos page and verify your new video appears
🎉 Congratulations! Your video is now live and accessible to everyone. Share the link on YouTube, social media, or wherever your audience is.
10

Final Checklist

5 minutes

Do a final check of your published video to ensure everything is perfect.

On the Live Site

  • Video appears in Videos page grid
  • Video card shows correct title, description, tags
  • Thumbnail displays (custom or auto-generated)
  • Clicking card opens correct detail page
  • Detail page URL is video.html?id=video-003
  • All metadata is correct (title, description, category, date)
  • Tags are displayed properly
  • YouTube button links to correct video (if URL provided)
  • Source Repo button works (if provided)
  • Live Link button appears only if enabled
  • Code files are syntax highlighted
  • Copy buttons work on each file
  • Copy All button works
  • Download buttons work (single file or ZIP)
  • Mobile responsive (check on phone)

Next Steps

  • Share on YouTube: Add the video detail page URL in your YouTube video description
  • Promote: Share on social media, Reddit, programming communities
  • Track engagement: Check GitHub Stars, site visits, code copies
  • Iterate: Read feedback, improve future videos based on what works
You're done! Repeat this workflow for every new video. It gets faster each time — eventually you'll complete the whole process in under 20 minutes.
